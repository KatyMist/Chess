> [!NOTE]
> **О проекте.** Шахматы на одном экране для двух игроков, написанные для практики React и TypeScript: логика вынесена в модели (`Board`, `Cell`, `Figure` и наследники), а компоненты отвечают только за отображение.
>
> **About the project.** Hot-seat chess for two players, built to practice React and TypeScript: game logic lives in models (`Board`, `Cell`, `Figure` and its subclasses), while components only handle rendering.

---

## Возможности · Features

- Ходы всех фигур, подсветка доступных клеток, превращение пешки<br>
  All piece moves, highlighted available squares, pawn promotion
- Шах, мат и пат<br>
  Check, checkmate and stalemate
- Таймер с настройкой минут на игрока (или игра без таймера)<br>
  Timer with configurable minutes per player (or play without it)
- Отмена хода<br>
  Undo move
- Панели съеденных фигур и подсказка, как ходит каждая фигура<br>
  Captured pieces panels and a guide to how each piece moves
- Адаптив: ноутбук, планшет, телефон<br>
  Responsive: laptop, tablet, phone

---

## Запуск · Run

```bash
npm install
npm start        # dev-сервер / dev server, порт / port 3000
npm run deploy   # сборка и деплой на GitHub Pages / build & deploy to GitHub Pages
```
